项目介绍

pyttsx3是一个Python的文本转语音转换库，与其他库不同的是，它可以完全离线工作。

主要特点：

  • 完全离线：不需要网络连接即可将文本转换为语音，非常适合需要隐私保护的环境。
  • 多种语音选择：可以使用系统中安装的各种语音，包括不同语言和不同发音人的语音。
  • 灵活的控制：可以调整语速和音量，以获得最佳的听觉效果。
  • 音频保存：可以将生成的语音保存为MP3文件，方便在其他地方使用。
  • 简洁的API：提供了简单而强大的API，只需几行代码即可完成文本转语音。

支持的操作系统：

  • Windows：使用SAPI5引擎
  • macOS：使用AVSpeech和NSSpeechSynthesizer
  • Linux：使用eSpeak引擎

应用场景：

  • 自动朗读文档和网页
  • 创建语音助手和聊天机器人
  • 无障碍访问支持
  • 教育和培训应用
  • 自动化测试和演示

安装

pip install pyttsx3

注意：如果安装过程中出现错误，请先升级wheel版本：

pip install --upgrade wheel

Linux用户：如果声音输出不正常，请安装espeak-ng和libespeak1：

sudo apt update && sudo apt install espeak-ng libespeak1

基本使用

import pyttsx3
engine = pyttsx3.init()
engine.say("我将朗读这段文本")
engine.runAndWait()

单行使用：

import pyttsx3
pyttsx3.say("我将朗读这段文本")

调整语音、语速和音量

import pyttsx3
engine = pyttsx3.init()

# 语速
rate = engine.getProperty('rate')   # 获取当前语速
print(rate)                        # 打印当前语速
engine.setProperty('rate', 125)     # 设置新的语速

# 音量
volume = engine.getProperty('volume')   # 获取当前音量级别（0-1）
print(volume)                          # 打印当前音量
engine.setProperty('volume', 1.0)       # 设置音量级别

# 语音
voices = engine.getProperty('voices')       # 获取语音信息
# engine.setProperty('voice', voices[0].id)  # 男声
engine.setProperty('voice', voices[1].id)   # 女声

engine.say("Hello World!")
engine.say('我的当前语速是 ' + str(rate))
engine.runAndWait()
engine.stop()

保存到文件

import pyttsx3
engine = pyttsx3.init()
engine.save_to_file('Hello World', 'test.mp3')
engine.runAndWait()
