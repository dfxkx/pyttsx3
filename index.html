项目介绍

什么是 pyttsx3？

pyttsx3是一个开源的Python文本转语音库，允许你将文本转换为自然的语音输出，完全无需依赖云端API，所有处理都在本地完成。

主要特性

  • 完全离线运行，无需互联网连接
  • 支持Windows、macOS和Linux跨平台使用
  • 支持多种语音引擎：sapi5、nsss、espeak
  • 可以动态切换语音
  • 调节语速和音量
  • 保存语音输出为音频文件

项目背景

pyttsx3项目旨在提供一个简单易用、功能强大的离线文本转语音解决方案，帮助开发者轻松在他们的应用程序中添加语音功能，无需担心API调用限制和网络延迟问题。

使用指南

1. 安装

# 使用pip安装
pip install pyttsx3

# 对于Linux用户，需要安装espeak
sudo apt-get install espeak

2. 基础使用

import pyttsx3

# 初始化引擎
engine = pyttsx3.init()

# 朗读文本
engine.say("Hello World")
engine.say("这是一个测试")

# 等待朗读完成
engine.runAndWait()

3. 高级功能

调节语速

rate = engine.getProperty('rate')
engine.setProperty('rate', rate-50)  # 减慢语速

调节音量

volume = engine.getProperty('volume')
engine.setProperty('volume', volume+0.25)  # 增大音量

切换语音

voices = engine.getProperty('voices')
engine.setProperty('voice', voices[1].id)  # 切换到女性语音

4. 保存到文件

engine.save_to_file('Hello World', 'test.mp3')
engine.runAndWait()
